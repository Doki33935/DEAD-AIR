## Проверка игры

- Внешний игрок без подсказок команды проходит с начала до финала мышью.

- Записать реальное первое время; наша цель 20–30 минут, без ожидания ради секундомера.

- Проверить ошибки частоты, источника, времени записи и ответа: игрок понимает причину и может продолжить.

- T1 можно развернуть; TX повторить; T2 найти по трём ступеням помощи.

- Поиск T2 не расходует часы. Загрузка сохраняет найденные предметы, записи и один результат 50/50.

- Пройти прямой запрос, обе стороны делегирования, местный журнал и поздний прямой запрос.

- OFF сразу выключает радио. Хороший финал заканчивается отъездом, плохой — поворотом и голосом.

- Windows ZIP запускается без редактора на другой машине; меню/перезапуск тоже доступны мышью.

Для официального плейтеста нужен минимум один человек вне команды. В PDF: обезличенный тестировщик, аудитория, дата, версия, устройство, условия, время, наблюдения, проблемы, исправления и повторная проверка. Контакты человека не собирать. [Требования к проверке продукта](https://professor0ice.github.io/NTO_RKI_26-27_Second_Stage/product/index.html).
