# Слава — первая механика радио

Работаем в UE 5.0.3. Используй существующий `Radio_1` на `ThirdPersonMap`. Первый результат — игрок находит контрольный вызов базы и слышит номер **27**.

1. **Подключи питание.** Клик по `button_1` включает и выключает приёмник. При выключении речь и шум останавливаются сразу. Индикатор показывает состояние.
2. **Сделай настройку частоты.** `Tumbler_1` меняет частоту с шагом **5 кГц** в диапазоне **153,400–153,550 МГц**. Храни частоту целым числом в кГц. Показывай текущее значение с тремя знаками после запятой. Поддержи колесо и видимые кнопки «−» и «+», чтобы хватало обычных кликов мышью.
3. **Сделай один сигнал.** На **153,450 МГц** доступен вызов базы с номером **27**, на соседних частотах слышен шум. Для первой проверки подойдёт временная запись. Частота и клип задаются данными, чтобы следующий сигнал добавить без новой ветки Blueprint.
4. **Подключи громкость.** На `ThirdPersonMap` ручка `Radio_Volume_Knob` прикреплена к радио. Для переиспользуемого прибора добавь `SM_Radio_Volume` в компоненты `Radio_1` с той же локальной привязкой, удали дублирующий актор с карты и подключи общую громкость речи и шума. `Tumbler_2` — ручка усиления на модели. Её игровое поведение отложи до проверки базового цикла.
5. **Проверь вход и выход.** Игрок может приблизиться к аппарату, включить его, настроиться, услышать вызов и вернуться к общему виду мышью.

**Приёмка.** Включить радио на соседней частоте → услышать шум → настроить 153,450 → услышать «27» → уйти с частоты → выключить радио во время повторного вызова. Состояние и звук соответствуют каждому действию.

ЭЛТ, архив и таймер подключаются отдельным этапом. К первому показу достаточно тестовой сцены, одной передачи и видимой частоты.
