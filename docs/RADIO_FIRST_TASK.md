# Слава — первая механика радио

UE 5.0.3. Образец уже находится в `Content/RadioExample`: открыть `RadioExampleMap`, нажать Play. Актуальный разбор Blueprint, виджета, PNG и проверки — [раздел 11 плана UE](UE5_ARCHITECTURE.md#11-образец-радио-для-славы--управление-удержанием-лкм).

По заданию Doki от 19 ноября ручки регулируются **круговым движением мыши вокруг центра при удержании ЛКМ**. Верхний ряд: частота / фильтр речи / громкость. Клики по 5 кГц, колесо и отдельная панель «−/+» из прежнего задания отменены. Встроенный экран уже показывает гладкую волну, частоту, громкость, фильтр и состояние приёма.

Следующая работа Славы:

1. Пройти проверку образца по разделу 11, затем перенести управление и виджет в существующий `Radio_1` на `ThirdPersonMap`. Сохранить исходные привязки всех деталей; отдельный `Radio_Volume_Knob` заменять компонентом только после проверки.
2. Добавить вход к прибору и возврат к общему виду мышью. Не дублировать состояние между основным актором и виджетом.
3. Перенести станцию 153,450 МГц и клипы в данные, чтобы следующая передача добавлялась строкой. Сохранить раздельные речь/помехи: фильтр меняет только слой помех, громкость — оба; регулировка не перезапускает речь.
4. Соединить услышанный номер **27** с журналом и первой квитанцией. Затем показать цельный путь: приблизиться → питание → настройка → фильтр → услышать номер → отчёт → квитанция → общий вид.

Исходные `Radio_1` и `ThirdPersonMap` образцом не заменены. ПК, архив и таймер остаются отдельным этапом. Проверка одной тестовой сцены не означает готовность всего игрового цикла.
