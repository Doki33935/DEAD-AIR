# DEAD AIR / «Мёртвый эфир»

Камерный психологический триллер о ночном операторе горной радиостанции. Декабрь 1999 года, одна комната, всё управление мышью.

**Unreal Engine 5.0.3 · демо 20–30 минут · готовность 29.11.2026 · сдача продукта 01.12.2026.**

Стартовая карта — **`Content/UI/MainMenuMap`**. Из неё мышью доступны новая игра, продолжение, загрузка трёх слотов, настройки и выход. В игре кнопка **МЕНЮ** открывает паузу и сохранения. Оформление по макетам Прохора, IBM Plex Mono Medium/SemiBold, видеоподложка через встроенный ElectraPlayer. [Переходы и инструкция Славе](docs/MAIN_MENU_FLOW.md). Сохранения пока восстанавливают состояние учебного радио; сюжетный прогресс подключается следующим этапом.

На GitHub в `dev` есть ранний UE-прототип и модель радио Ярика. Добавлен пример радио на Blueprints/UMG: открыть `nto_dead_air/nto_dead_air.uproject` в **UE 5.0.3**, карту `Content/RadioExample/RadioExampleMap` и нажать Play. Ручки вращаются **с зажатой ЛКМ круговым движением мыши вокруг центра** (частота / фильтр речи / громкость), чувствительность снижена, верхнее окно при захвате показывает бегущую осциллограмму записи, снизу расположены частота, громкость, фильтр и статус приёма. Фильтр доступен после захвата сигнала; эфир продолжается при уходе с частоты и возвращается без перемотки. Отдельной панели поверх камеры нет. [Разбор Blueprint и виджета для Славы](docs/UE5_ARCHITECTURE.md#11-образец-радио-для-славы--управление-удержанием-лкм). Перед открытием после получения изменений выполнить `git lfs pull`. Полный игровой цикл и упакованная Windows-сборка ещё не приняты.

Новая техническая сцена стола и кассетной деки — **Content/StationIntegration/StationIntegrationMap**. Адаптированы модели Ярика и логика Славы, добавлены камеры обоих плеч, кассетный цикл и связь с радио. [Результаты проверки и порядок интеграции](docs/UE5_ARCHITECTURE.md#13-подготовка-стола-деки-и-камеры--19-ноября). Комната и изображения текстур радио ещё ожидаются; сцена пока открывается отдельно от основной смены.
