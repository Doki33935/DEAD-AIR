# DEAD AIR / «Мёртвый эфир»

Камерный психологический триллер о ночном операторе горной радиостанции. Декабрь 1999 года, одна комната, всё управление мышью.

**Unreal Engine 5.0.3 · демо 20–30 минут · готовность 29.11.2026 · сдача продукта 01.12.2026.**

Ниже описан образец радио/деки и целевой маршрут. Полный сюжетный цикл ещё не интегрирован; актуальные проверки относятся к учебной сцене. [Состояние и ограничения](docs/PROJECT_CONTEXT.md).

Стартовая карта — **`Content/UI/MainMenuMap`**. Из неё мышью доступны новая игра, продолжение, загрузка трёх слотов, настройки и выход. Верхняя кнопка МЕНЮ убрана по запросу Doki; вход в паузу через будущую кровать запланирован, пока игрового входа в меню нет. Оформление по макетам Прохора, IBM Plex Mono Medium/SemiBold, видеоподложка через встроенный ElectraPlayer. [Переходы и инструкция Славе](docs/UE5_ARCHITECTURE.md#4-меню-и-сохранение). Новая игра и продолжение открывают общий стол с радио и декой; сохранения восстанавливают учебный эфир и кассету. Сюжетный прогресс подключается следующим этапом.

Игровая карта — **Content/StationIntegration/StationIntegrationMap**. Сидячий обзор на высоте 137 см направлен на приборы, дека приведена к размерам исходной комнаты. Окна прозрачные; освещение тусклое: центральная лампа 3300 K, локальное пятно у приборов 2900 K. Системный блок убран, столешница у компьютера расширена; реквизит стоит на столе, кассета углублена в отсек под прозрачную крышку. Перед монитором добавлена CC0-клавиатура; новая тарелка Ярика заменяет старую. По решению Doki курсор скрыт в обзоре, виден у приборов и в меню; крестика нет. Обычный обзор стола ограничен ±48°; удержание мыши у правого края плавно переводит взгляд к кровати, у левого — обратно к столу. У кровати сектор ±16°, вертикальный наклон ±14°. Прибор под центром экрана подсвечивается, ЛКМ приближает камеру, ПКМ возвращает к столу. Быстрые переходы убраны; при появлении у прибора курсор центрируется. При настройке приборов камера неподвижна. Радио: круговое вращение с зажатой ЛКМ, всегда доступный фильтр с разными оптимумами по данным станции, плавные помехи с изменением тембра и полосы, осциллограф сверху и отдельная спектрограмма под ним. Встроенные цифровые окна сохранены по правкам Doki. Кнопка питания вдавливается/светится; у деки есть визуальные нажатия. При OFF все три экрана и их свет погашены. Дека: физические фиксируемые клавиши PLAY / FF ×3 / STOP / REW ×3 / REC; нижняя учебная панель скрыта. Рабочая кассета использует бесплатную модель из комнаты; её ступицы анимированы материалом при PLAY, ускоряются на FF и идут обратно на REW. Кассета плавно переносится между лотком и декой, декоративные дубликаты убраны. Радио и дека звучат независимо. Субтитры появляются по позиции слышимой записи и скрыты в меню. Вход в игру проявляет стол из чёрного за две секунды; возврат в главное меню затемняет изображение.

Открывать `nto_dead_air/nto_dead_air.uproject` в **UE 5.0.3**, после получения изменений выполнить `git lfs pull`. [Архитектура и проверки](docs/UE5_ARCHITECTURE.md), [меню и сохранения](docs/UE5_ARCHITECTURE.md#4-меню-и-сохранение). Комната из архива уже перенесена в StationIntegrationMap без установки UE 5.4: мебель, стены, рабочий стол и текущие приборы; [результат и ограничения переноса](docs/UE5_ARCHITECTURE.md#5-комната-материалы-и-художник). Финальная отделка приборов, сюжетная запись REC и полный игровой цикл ещё не приняты.

Взаимодействие теперь разделено: BP_OperatorController — мышь/выбор/курсор, BPI_Instrument — контракт прибора, BP_DeskWorkstationRig — только камера. Для художника подготовлена отдельная папка на рабочем столе DEAD_AIR_3D_ARTIST с FBX/PNG и соответствиями материалов. Шаблонный контент и неиспользуемые прототипы удалены по графу ссылок; локальные сохранения сохранены.
