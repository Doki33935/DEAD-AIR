# DEAD AIR / «Мёртвый эфир»

Камерный психологический триллер о ночном операторе горной радиостанции. Декабрь 1999 года, одна комната, всё управление мышью.

**Unreal Engine 5.0.3 · демо 20–30 минут · готовность 29.11.2026 · сдача продукта 01.12.2026.**

Ниже описан локальный образец и целевой маршрут. Последние доработки приборов ещё не приняты: последний PIE-прогон — 40 проверок, 2 ошибки. Текущий этап ограничен Markdown; публикация документов не включает локальные изменения UE. [Состояние и ограничения](docs/PROJECT_CONTEXT.md#статус-решений).

Стартовая карта — **`Content/UI/MainMenuMap`**. Из неё мышью доступны новая игра, продолжение, загрузка трёх слотов, настройки и выход. В игре кнопка **МЕНЮ** открывает паузу и сохранения. Оформление по макетам Прохора, IBM Plex Mono Medium/SemiBold, видеоподложка через встроенный ElectraPlayer. [Переходы и инструкция Славе](docs/MAIN_MENU_FLOW.md). Новая игра и продолжение открывают общий стол с радио и декой; сохранения восстанавливают учебный эфир и кассету. Сюжетный прогресс подключается следующим этапом.

Игровая карта — **Content/StationIntegration/StationIntegrationMap**. По решению Doki курсор скрыт в обзоре, виден у приборов и в меню; крестика нет. Движение мыши мягко поворачивает взгляд, прибор под центром экрана подсвечивается, ЛКМ приближает камеру, ПКМ возвращает к столу. Кнопки «СТОЛ / РАДИО / ДЕКА» дают прямой путь мышью. При настройке приборов камера неподвижна. Радио: круговое вращение с зажатой ЛКМ, всегда доступный фильтр с разными оптимумами по данным станции, плавные помехи с изменением тембра и полосы, осциллограф сверху и отдельная спектрограмма под ним. Встроенные цифровые окна сохранены по правкам Doki. Кнопка питания вдавливается/светится; у деки есть визуальные нажатия. Субтитры появляются по позиции слышимой записи.

Открывать `nto_dead_air/nto_dead_air.uproject` в **UE 5.0.3**, после получения изменений выполнить `git lfs pull`. [Архитектура и проверки](docs/UE5_ARCHITECTURE.md), [меню и сохранения](docs/MAIN_MENU_FLOW.md). Финальная комната, текстуры радио, полноценный корпус кассеты, сюжетная запись REC и полный игровой цикл ещё не приняты.
